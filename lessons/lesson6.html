Hermes on your laptop

✏️ Quick basics: the terminal

From here on, we live on your laptop, not in a browser. You'll set us up by typing a few commands.

The terminal is a window where you type commands instead of clicking. You type (or paste) one line after the $, press Enter, and the computer prints its answer. Spelling matters: one wrong letter and it says command not found.

Try it. Type a command, press Enter.
$
Try:

On a Mac, open the app called Terminal. On Windows, you'll get a Linux terminal on the next page.

🤔 Is it safe to paste commands?
Only from places you trust, like the official Hermes docs or this course. A command can change anything on your laptop, so read it first, and never paste one from a stranger.

Now: what are we installing?

What Hermes is

Hermes Agent is a free, ready-made app that does everything you built by hand: the loop, tools, the chat, memory, MCP and A2A. It runs on your laptop and works with almost any LLM. It also adds what a real team needs every day: bots with their own roles, messages from your phone, and jobs on a schedule.
Hermes = the program around the LLM, already built

Install it

One command downloads and installs Hermes and everything it needs. On Windows, you first add WSL2, then run the same command inside it. When it's done, open a new terminal and check the version.
install → open a new terminal → hermes --version

Pick your laptop. Copy each line into your terminal, in order.
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Then close the terminal, open a new one, and check:

hermes --version

1. In PowerShell, opened as administrator. Then restart the laptop.

wsl --install

2. Open the new “Ubuntu” app. Inside it:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

3. Close Ubuntu, open it again, and check:

hermes --version

Checked against Hermes Agent v0.23 (November 2026). Hermes changes often: if a command doesn't work, see the Hermes docs.

🤔 Isn't there a normal app to download?
Yes: Hermes Desktop, for Mac and Windows, from the Hermes website. You'll use it for Bot Mode in Lesson 7. The terminal install above is still worth doing: the later lessons (Telegram, schedules, Docker) use it.

Hermes is in. Now it needs a brain.

Local or online?

Hermes needs an LLM. A local model runs on your own laptop with Ollama: free and private, but it needs memory (about 8 GB for a small model, 16 GB for a medium one) and is weaker and slower. An online model is reached through a service like OpenRouter: stronger and faster, and you pay per use, usually a few dollars a month.

Cost is counted in tokens (pieces of words), priced per million:
cost per month = million tokens per month × price per million
200,000 tokens a day × 30 = 6 million. At $0.50 per million: 6 × 0.50 = $3 a month.

Try your own numbers.

Local model: $0, but only if your laptop has the memory.

Or both: a local model first, and an online one only when it fails. That's called a fallback.

🤔 Which should I pick for a real business?
Start local and free while you learn. For a team you rely on every day, a cheap online model is usually more dependable: small local models often lose track in long agent tasks. Prices change fast, so check them when you choose.

Connect the model

Run hermes model and answer its questions. Hermes saves your answers in two files. Settings go in ~/.hermes/config.yaml. Secrets, like an API key (the password for an online model), go in ~/.hermes/.env, kept apart so you can share settings without sharing secrets.
settings → config.yaml · secrets → .env

Pick one. See what hermes model asks, and what it saves.

~/.hermes/config.yaml

~/.hermes/.env

~ means your home folder. A name starting with a dot, like .hermes, is hidden in normal file windows.

🤔 My local model forgets things mid-task. Why?
Ollama reads only a short text by default, and an agent's text is long. Hermes wants room for at least 64,000 tokens. Start Ollama with OLLAMA_CONTEXT_LENGTH=64000 ollama serve, or use an online model.

Your first chat

Type hermes and press Enter. You're now chatting with an agent that runs the same loop you built: it thinks, uses a tool, looks at the result, and answers. One difference is big: its tools are real. It can read files and run commands on your laptop.
