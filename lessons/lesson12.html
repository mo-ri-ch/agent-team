Run it every day

What keeps it running

Everything your team does, chats and scheduled jobs, runs inside each bot's gateway. If a gateway stops, that bot goes quiet. In Lesson 9 you installed each gateway as a service: the computer restarts it if it crashes, and starts it again when the computer starts. A service can't wake a sleeping laptop, though.
gateway stops → bot goes quiet

Something happens. Does the team come back by itself?

Check a bot any time with marketing gateway status.

🤔 On Windows too?
With WSL2, the services live inside Ubuntu, and Ubuntu only starts when something opens it. After Windows restarts, open the Ubuntu app once (or set it to open when you log in), and the gateways start with it.

And when it's running, but something's off?

Is it healthy?

Three commands answer most questions. status: is it running? logs: what did it do, and what went wrong? doctor: is the setup itself OK? Start with status, then read the logs. Logs are the bot's diary: every message, job and error, with the time.
status → logs → doctor

Which command do you run first?

marketing gateway status   # running?
marketing logs             # what happened, and errors
hermes doctor              # config, keys and services OK?

Now, the day a disk dies.

Back it up

hermes backup saves all of ~/.hermes into one zip: every bot, its memory, SOUL.md, schedules and keys. Because it holds keys, treat the zip like a password. Two more things: your business files live in the shared folder, not in Hermes, so copy that too; and a backup on the same laptop dies with the laptop.
back up Hermes and the shared folder · keep it off the laptop

Choose your habits. Then the laptop's disk dies.
hermes backup                    # → ~/hermes-backup-<date>.zip
hermes import hermes-backup-….zip # on a new machine, gateways stopped

Backups also make updates safe.

Update safely

Hermes gets a new version almost every week: fixes, and sometimes new settings. hermes update pulls it in and restarts the gateways. Update when you're around to check, never right before a busy sale day, and take a backup with it, so you can go back.
quiet time · backup · update · check

    Laptop or server?

    A laptop is fine if it stays on when jobs run. If it sleeps at night, or travels with you, move the team to a small server: a computer you rent online, about $5 a month. The gateway only calls out to Telegram and the model, so you open nothing on it except your login. A server that small can't run a local model, so bots there use an online one.

    The Analyst's projection

    Each Monday the Analyst also shows where today's pace leads in 1, 2 and 3 years. That's a projection: it assumes the same growth every month. It's useful for planning fabric, money and help, but it is not a promise. Its SOUL.md says: “Label every future number as a projection, and say what it assumes.”
    in n months = today × (1 + growth)ⁿ
    60 orders, 3% a month: 60 × 1.03¹² ≈ 86 in a year.
