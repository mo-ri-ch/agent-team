What a bot reads

A bot reads its own instructions + the chat so far. The function text_for builds exactly that, one line at a time: the instructions, an empty line, Chat so far:, one line per message, then the bot's own name, so the LLM writes the next line as that bot.

Taking turns

The bots sit in a list, and the turns are counted 0, 1, 2 … The bot for a turn is found with %: it gives what's left over after dividing. With 2 bots:

turn 3 → 3 ÷ 2 = 1, with 1 left over → 3 % 2 is 1 → bots[1], the Marketer.
bot = bots[turn % number of bots]

Pick how many bots. Then go turn by turn.

The left-over always goes 0, 1, … up to one less than the number of bots, then back to 0. So each bot gets a turn, in order, round and round.

Round and round… until when?

DONE, or the turn limit

The Marketer's instructions say: when the caption is final, end with DONE. So after each reply, the loop checks for DONE and stops. In case it never comes, it also stops after a set number of turns, the turn limit.
stop at DONE, or at the turn limit

A real LLM

In Colab, each bot's fake LLM is swapped for a real one. Its text ends with chat lines like CEO: …, so it guesses more chat lines and often writes other bots' messages too. Here's that kind of reply (an example made for this page).

The Marketer's LLM wrote all four lines. Tap the first one it shouldn't have written.

So the program keeps the reply only up to the first line that starts with another name. If it starts with its own name, that name is dropped.
cut the reply where another name starts

🤔 Which real LLM, and does it cost anything?
A small, free model, Qwen2.5 1.5B, that runs inside Colab. You only need a Google account. Small models make more mistakes, and may never write DONE, so the turn limit matters. These bots have no tools yet, so the Researcher's instructions tell it not to make up facts.

The code

# The shared chat: a list of messages, in order.
# Each message is a dictionary: who wrote it, and what it says.
chat = []

def post(who, text):
    chat.append({"who": who, "text": text})
    print(f"{who}: {text}")

# A bot: a name, its own instructions, and an LLM to write with
researcher = {"name": "Researcher",
              "instructions": "You are the Researcher at Amal Designers, a kids' dress brand. Find trends and prices. Say where each fact came from."}
marketer = {"name": "Marketer",
            "instructions": "You are the Marketer at Amal Designers. Write one Instagram caption from the facts in the chat. When it is final, end with DONE."}

# What a bot reads: its own instructions + the chat so far.
# The last line is its own name, so the LLM writes as that bot.
def text_for(bot):
    lines = [bot["instructions"], "", "Chat so far:"]
    for m in chat:
        lines.append(m["who"] + ": " + m["text"])
    lines.append(bot["name"] + ":")
    return "\n".join(lines)

# Fake LLMs: each bot's replies, written by hand, in order
researcher_replies = ["Pastel frocks are big for birthdays this month (from 3 kids' shops). Most cost ₹1,200 to ₹1,800.",
                      "Yes: buyers in those shops' reviews ask for handmade. Say that."]
marketer_replies = ["Draft: “Twirl-ready pastel frocks for birthdays 💫 DM to order!” Researcher, anything to add?",
                    "Final: “Twirl-ready pastel frocks for birthdays 💫 Handmade by Amal Designers. DM to order!” DONE"]

def fake_researcher(text):
    return researcher_replies.pop(0)

def fake_marketer(text):
    return marketer_replies.pop(0)

researcher["llm"] = fake_researcher
marketer["llm"] = fake_marketer

# Taking turns: turn 0 → bot 0, turn 1 → bot 1, turn 2 → bot 0 …
# (% gives what's left over after dividing: 2 % 2 is 0, 3 % 2 is 1)
print(3 % 2)

def run_chat(task, bots, turn_limit=6):
    post("CEO", task)
    for turn in range(turn_limit):
        bot = bots[turn % len(bots)]
        reply = bot["llm"](text_for(bot))
        post(bot["name"], reply)
        if "DONE" in reply:
            return "Done after " + str(turn + 1) + " turns."
    return "Stopped: the turn limit was reached."

print(run_chat("Write a caption for the new pastel party frock.", [researcher, marketer]))
